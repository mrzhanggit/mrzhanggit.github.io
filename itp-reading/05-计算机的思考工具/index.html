24 计算机施展魔法的7个秘密（上）· 从盒子和豆子开始

REGISTER MACHINE

1957 年，逻辑学家王浩（哥德尔的学生）发明了寄存器机。它简陋得可爱：若干寄存器像大盒子，里面可放任意多（0 到无限多）的豆子；处理单元只会三条指令——

1

结束

表示将自己停止或者关闭。

2

增量

将寄存器 n 中的数字加 1，或者说在盒子 n 中再填入一粒豆子，然后进入下一步。

3

减量（遇 0 跳转）

将寄存器 n 中的数字减 1（从盒子中拿走一粒豆子）；若寄存器已是 0、无法再减，则跳转至指令指定的另一个步骤——这个条件分支是全部魔法的关键。

就这三招。用 RAP（寄存器汇编程序）语言写出「程序1：相加［1,2］」，寄存器 1 每减一次、寄存器 2 就加一次，直到寄存器 1 变成 0——处理单元并不知道寄存器里的数字，它只能识别出「空了」，像个盲人看不见盒子里有多少豆子却摸得出空盒。

于是：即使不知道哪两个数相加、不知道数字是什么、甚至也不知道加法是什么，寄存器机也能完美地完成累加计算！

随后是移动［4,5］、复制［1,3］、无损加法［1,2,3］——想内化它们，可以取几个杯子写上地址、抓一把硬币「手动模拟」，或者「先用几分钟去变成一部寄存器机（就像一个演员要去饰演哈姆雷特那样）」。

加法熟练后，减法要注意「旗帜」寄存器标记正负号；乘法是「n 乘以 m 表示 m 个 n 相加」，用计数器从 m 递减到 0；除法则不断减去除数并记录次数，还要小心核查除数是否为 0——为 0 时让专门的报错寄存器拉响警报：「快！我就要除以 0 了！」。书末附录收有全部练习题的答案。

SEVEN SECRETS
秘密内容
秘密 1发挥能力，无需理解力：有些东西——如一台寄存器机——它能完成精密的运算，但无需理解自己在做什么。
秘密 2寄存器中的数字会代表什么取决于我们所编写的是什么样的程序。
秘密 3寄存器中的数字可以表示任何事物——寄存器原则上可以「识别」所有用数字表示的图案或特征（黑白图片、OCR 文字识别，用的都只是算术）。
秘密 4既然一个数字可以表示任何事物，那么它就一定能表示一条指令或是一个地址。
秘密 5所有可行的程序都能由一个单独的数字指代，都可以被看作是一串指令，等待通用万能机去执行。
秘密 6自图灵的假想纸带机之后，计算机所有方面的改善，提高的都只是运算速度。
秘密 7没有再多的秘密了！

第 5 条要归功于图灵：通用图灵机是一部通用拟态机——自带程序 A 的多用途通用机，喂给它各种程序（软件）它就能按要求办事。笔记本电脑能做的事通用寄存器机也一样能做，反之亦然。

而第 6 条最让人意外：冯·诺依曼拓宽交流窗口（一次读多比特，即「冯·诺依曼瓶颈」）、硬连线的专门电子路线、并行机、每秒超过一亿亿次浮点运算的富士通 K-computer——自图灵以来专家们所做的一切，就是要让寄存器机能做的一切工作变得高效起来，其他别无所求。

你大脑的即时运算速度与此旗鼓相当：约一千亿个神经元组成的卓越并行处理机，只是神经元比电路慢得多——所以让机器更快的一个方法是把它做得更小：光走一尺大致需要十亿分之一秒，想让两个程序通讯更快，就让它们离得更近些。

25 虚拟机 · 模仿硬件运行的计算机程序

VIRTUAL MACHINES

计算机不像割草机或开瓶器——它不需插上不同附件，只要点开不同的程序（一串串由 0 和 1 组成的超长数字），就能转换成不同的装置。每套装置系统都是一台单独的小机器，没有齿轮、轴承、电线或者滑轮，这就是模拟机——「构成它们的是指令」。

计算机上唯一「可移动的部件」是硬件上数百万个可在 1 态和 0 态之间切换的小空位。

「虚拟机」最初（波佩克与戈德堡，1974）指「实体机的一种独立有效的复制品」：在硬件 B 上模拟硬件 A，你写的程序应该畅通无阻。它像小丑模仿手臂打石膏的人——肢体动作做出相应调整，旁观者看不出破绽。

概念随后扩展：操作系统本身就是一部虚拟机；Java 虚拟机（JVM）更是只作为软件机存在，让同一程序跑在 PC、Mac 与 Linux 上——是 Java 的出现让今天的因特网变得如此丰富多彩。而广义地说，几乎所有程序都是虚拟机：一旦运行，通用计算机就被转成了专用计算机。

关键技巧是层层嵌套：一个用 Common Lisp 写的国际象棋程序，运行在 PC 佯装的 Windows7 上——PC 佯装 Windows 机，Windows 机佯装 Lisp 机，Lisp 机又佯装成国际象棋游戏机。这与关乎心智的小人儿功能主义中小人儿的层层嵌套并非巧合。

下棋时、说法语时大脑各层面到底发生了什么，目前还不得而知；但虚拟机给出了一种最好的解释：所有说法语的人脑中都藏着一套版本各异的法语虚拟机——你说「Donnez-moi le sel, s'il vous plait」，就能预见它的反应。

虚拟机推动着人类的创造和理解，实质性地完成了一些至今都超越我们想象的任务，比如完成航线预定、下象棋、预测天气、做记录等等——25 虚拟机

这些惊人的成就鼓励着我们：如果对大脑也采用类似（仅仅是类似）的技巧来实施逆向工程，或许我们也能得到一些收获。

ALGORITHMS

《达尔文的危险观念》里的那句话是本篇的题眼：

地球上的生命经由这种或者那种算法，在上亿年的时间里谱出了一棵布满枝桠的生命之树。——26 算法

「算法」一词得自 9 世纪波斯数学家花剌子模（Mûusâ al-Khowârizm）；直到 20 世纪 30 年代，图灵、哥德尔、丘奇这一代人的一系列创始性工作才确立了今人的理解。对丹尼特来说，算法概念有三个至关重要的特征：

①

底层中立

不管你用的是哪种符号体系，也不管你用的是铅笔还是钢笔，纸张或是羊皮卷，霓虹灯或者空中文字，都不会影响你运算长除法——依据的是逻辑结构，物质材料的因果力量不直接参与运算。

②

潜在无头脑

步骤出奇地简单，一个听话的白痴或一个简单的机械装置就能执行。算法就像为新手厨师设计的烹饪说明：「取一瓶标签上写有『干』字样的白葡萄酒，用螺旋开瓶器打开……」你只需充当一部食谱阅读器。

③

结果有保障

只要不出意外，它就能每次都按照同样的步骤运作。一种算法就是一份简单的、不易有出入的食谱。

计算机就是靠这些特点成就的：电子在硅芯片上飞来飞去，但计算机的能力与它们的因果特性完全无关——运算速度除外。同一算法用光纤分流光子更快，用纸笔则慢得很。是达尔文发现了算法的力量——不过他发现的不是一种算法，而是一大类相关的算法，只是他还没办法做出明确划分（详见第五部分）。

27 让电梯实现自动控制 · 机器取代人类的逻辑

ELEVATOR CONTROL

丹尼特年轻时的电梯还有操作员：转动奇怪的手柄，电梯总停得比楼层高出或下陷三五厘米，要提醒乘客「注意脚下」。操作规程被写成一本操作手册——「无论什么人，只要按照手册正确操作就一定能成为优秀的电梯操作员」。于是「玩具问题」来了：让程序员把手册变成程序。

先写伪代码（「如果呼叫楼层>所在楼层，那么上升，直到呼叫楼层=所在楼层即停止；开门。等待……

」），再转译成源代码——变量名直接显示作用（呼叫楼层 callfloor、总重量 weightsum），并附上让人能读懂意图的注释；编译器把源代码读录成目标代码，烧进只读存储器，装上电梯，连上传感器与效果器。

再见了！机器已经彻底取代了真实的人类操作员，遵守着同样的规则——真的是这样吗？不，它们只是近似于遵守着同样的规则。这是一种经典的中间状况：既不像人类那样逐字逐句保存规则随时查阅，也不像行星「按照」轨道运行。

我们人类也常处在这种中间状况——英语的 i/e 拼写规则人人「遵守」却说不全；每个十岁的母语孩子都能为脑中的英语虚拟机调出相当不错的目标代码，而语言学家至今写不出一本标准的规则手册。

临别提醒才是本章真正的靶子：源代码里的注释能帮程序员理解各部分的意图，但自然选择在大脑中安装的功能结构，就像一些没有注释的代码——

自然选择在我们的大脑中安装的那些功能结构就像是一些没有注释的代码，这些功能是有目的的，但由于代码并没有对结构的目的有所注释，大脑也就无从理解这些意图了。——27 让电梯实现自动控制

第三部分小结 · 分支跳转与算法

PART III SUMMARY

在图灵机发明之前，「计算者（computer）」是一种职业——工厂和政府雇佣成千上万的人为商业、航海、枪炮制造与银行做计算。图灵的大胆设想：大脑也可能是一名计算者，通过奴隶般地履行大量像增量、减量那样简单的指令完成信息处理。

他最具创新力的地方在于淘汰了那些笨拙环节——早期设想里，节骨点上永远得有一个员工、译者或图书管理员，一个领会所有输入信号的「理解器」。图灵把理解成分降到最低：他发明了条件分支跳转，通过（近似）识别 1 或者 0、A 或者 B 来确定（近似确定）走左边还是右边。

分支跳转和算法，这就是这个系统所需要的全部了，只要在虚拟机上叠加虚拟机，在其上再叠加虚拟机，一个个叠加下去，就能组装出具有各种识别水平的装置。——第三部分小结

50 年来我们一直为这一愿景努力，也发现了很多细小而棘手的问题：如果大脑可以比作计算机，那它肯定不是我们平时所用的那种计算机。带着这个澄清过的插曲继续上路：下一步，先探索意义在大脑中怎样生成、演化的力量如何在没有程序员的情况下设计出精妙构架，再去面对最狡猾的两个概念——意识和自由意志。
