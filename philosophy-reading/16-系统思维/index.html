四种思维的递进

第五章收官定位 · 系统思维不淘汰前三种，而是把它们装进去

这一课是第五章《思维模式》的第四节，也是整个第五章的收束。前面三节分别解决「看到了什么、为什么发生、怎样变化」，这一节进一步追问：

这些因素放到同一个整体里以后，彼此怎样连接、怎样相互影响，整个系统为什么能够存在，又会走向哪里？
本讲开篇的核心问题

四节课全部讲完，现在可以真正看清第五章的总体结构——四种思维各自回答一个核心问题：

感

感性思维

主要看现象与特征 —— 发生了什么？

因

因果思维

主要看原因与结果 —— 为什么发生？

辩

辩证思维

主要看张力与变化 —— 它正在怎样变化？

系

系统思维

主要看整体关系与反馈 —— 这些因素连接起来，整体会怎样？

所以第五章并不是简单地把四种思维按「低级→高级」排列。更准确的理解是一条认知递进链：

观察
感性思维 · 看现象
解释
因果思维 · 找原因
动态理解
辩证思维 · 看变化
整体整合
系统思维 · 看整体

常见误解 ✕

  • 系统思维比前三种「更高级」，淘汰了前三种思维

更准确的理解 ✓

  • 系统思维之所以强，是因为它需要把前三种思维全部装进去：系统里仍然需要观察现象、找到因果、理解矛盾和变化，最后再研究它们怎样组成一个整体
它需要把前三种思维全部装进去。
整理者认为这是老师这一课最值得保留的观点
貳

什么叫系统

整体行为不能通过孤立研究单个部分得到

老师不断强调「存在」「条件」「价值」。如果用现代系统语言表达，可以先记住这个定义：

一组彼此连接的组成部分，它们通过相互作用形成一个整体，并表现出单个部分本身没有的整体行为。
整理者用现代系统语言对「系统」的定义

例如一个社区卫生服务中心，不只是：医生 + 护士 + 药品 + 房屋。真正的系统还包括——

患者医保政策流程绩效机制信息系统转诊关系公卫任务社区居民时间安排 …

这些因素之间相互影响以后，才形成「这个中心实际上怎样运行」。系统的整体行为，不能简单通过孤立研究单个部分得到——这是应用型系统思维的基本共识。

叁

第一步 · 目的与边界

你怎样定义问题，就决定了你会看见哪些因素

系统思维最重要的第一步，不是马上列因素，而是先确定「我们研究的是哪个系统」——这是老师讲「功能、目的、边界」时真正触及的核心。同一个医院，两种问法就是两个系统：

问一

怎样提高医院收入？

这是一个系统

问二

怎样提高医疗服务能力，同时控制医保风险、保证质量和患者满意度？

系统边界已经完全不同

你怎样定义问题，就决定了你会看见哪些因素。
整理者对「边界」的提炼 · 本节主旨

现代系统实践同样强调：系统边界并不是永远客观固定在那里，而是与观察者研究什么问题、承担什么责任有关。因此第一问应该是「我的目标到底是什么？」接着问：为了回答这个目标，哪些东西应该放进系统？哪些暂时放在系统外？——这才是「边界」。

老师还说「价值=目的」。整理者提醒：目的、功能和价值非常相关，但最好不要完全等同。以一把刀为例：

功

功能

切割 —— 它能做什么

目

目的

医生拿它做手术，厨师拿它切菜 —— 我们希望它做什么

价

价值

取决于它对某个主体、某个目标产生什么意义 —— 这个功能对目标意味着什么

整理者的校正 ·「价值=目的」需要拆开
  • 目的、功能和价值非常相关，但最好不要完全等同
  • 这样拆开记更容易实际使用：功能＝它能做什么；目的＝我们希望它做什么；价值＝这个功能对目标意味着什么
肆

第二步 · 要素与「系统决定要素」

不能只抓住最显眼的一个原因
系统存在需要条件，条件就是要素。
老师原话 · 整理者认为方向基本正确

比如分析「居民家庭医生签约触达率低」这个系统，可能涉及：居民认知、家庭医生团队、社区网格、联系方式、上门时间、宣传材料、居民需求、信息系统、绩效机制……

普通分析 ✕

  • 「工作人员积极性不足。」—— 只抓住最显眼的一个原因，就此停住

系统思维 ✓

  • 继续追问「为什么积极性不足？」——可能又与任务设计、资源、反馈、激励、工作量相关，于是一个「原因」，又进入了更大的关系网
不能只抓住最显眼的一个原因。
系统思维与普通分析最大的差别之一
系统决定要素的价值。
老师原话 · 整理者认为很有启发性
例门锁与医生：同一个东西，在不同系统里价值完全不同▸
教室的门锁平时不起眼，但上课前打不开门时，它突然成为关键因素。一名医生：如果研究的是门诊服务系统，他的诊疗能力很关键；如果研究的是疫苗冷链管理系统，冷链设备、温控记录可能比这位医生更关键。

真正说明的是：一个要素的重要性取决于它在特定系统、目标和时间点中的作用。

重要提醒 · 功能价值 ≠ 人格价值
  • 「某人在某个系统暂时不是关键要素」绝不等于「这个人没有价值」
  • 不要把「系统中的功能价值」扩大成「整体人格价值」——这是两个不同层面
伍

第三步 · 要素不是重点，关系才是重点

系统是 A↔B↔C↔D，不是 A+B+C+D

要素堆叠 ✕

  • 一个系统是 A + B + C + D —— 医生、患者、医保、宣传、床位各列一行

关系结构 ✓

  • 一个系统是 A ↔ B ↔ C ↔ D —— 更重要的是画出它们怎样相互影响

老师列出了四种关系类型，这已经比简单列因素前进了一大步：

并列关系因果关系对立关系调控关系

比如分析中心业务增长，与其罗列因素，不如把相互影响的链条画出来：

宣传增加
居民认知增加
就诊增加
工作负荷增加
等待时间延长
满意度下降
后续就诊减少

链条画完，这时候你才真正看见：结构。

陆

补上反馈 · 因果不是直线，而可能是环

整理者建议一定要补进去的现代系统思维关键概念

这是源文整理者明确建议补上的概念：Feedback——反馈。它的意思是——一个结果产生以后，又回来影响自己的原因。两个方向都要看见：

增强增强反馈：越转越好▸
服务质量提高 → 居民口碑提高 → 患者增加 → 收入增加 → 有更多资源投入服务 → 服务质量进一步提高。
平衡平衡/抑制反馈：转过头会自动收紧▸
患者增加 → 医务人员负荷增加 → 等待时间增加 → 满意度下降 → 患者减少。

控制论的重要贡献就是研究这种「信息—反馈—调节」结构——维纳1948年的《控制论》，把反馈放在机器、生物甚至社会系统的控制与通信中讨论。

因果不是一条直线，而可能是一个环。
系统思维真正比普通因果分析强大的地方
柒

关键条件 · 驱动力与阻力

最少必要条件、冗余与瓶颈 · 有时最好的干预是减少阻力

老师讲的「要素的容易」，整理者从语境判断，大概率说的是「冗余」，也可能是在表达「最低必要条件」。这里可以拆成两个系统概念：

必要

必要条件

没有它，系统就不能正常运行 —— 比如门诊必须有合格医生

冗余

冗余

即使一个部分失败，系统还有备用能力 —— 只有一台关键设备，坏了业务就完全停止；有备用设备，系统韧性就更强

成熟的系统分析不仅问「哪些要素必不可少？」还要问：哪些地方没有冗余，一旦失效整个系统就会中断？——这对医院管理其实非常重要。

第五步是找「驱动力」和「阻力」。一个项目为什么推进？因为存在推动因素。为什么推进不动？因为同时存在阻碍因素。例如推动网格化工作：

推

驱动力

绩效要求 · 居民需求 · 领导推动 · 家医团队责任 · 信息建档需要

阻

阻力

工作量大 · 居民不在家 · 联系方式不全 · 职工积极性不足 · 时间冲突

系统思维真正要问：如果不改变阻力，只增加驱动力，会发生什么？很可能压力越来越大，系统反而出现疲劳。因此有时最好的干预不是「更用力推」，而是「减少阻力」——这就是系统思维比单纯「加强管理力度」更高级的地方。

整理者的校正 ·「焓=驱动力、熵=阻力」这部分建议不要记
  • 严格来说并不成立：恒温恒压下判断一个过程是否自发，通常使用吉布斯自由能 ΔG = ΔH − TΔS —— 焓与熵共同参与，熵并不是简单意义上的「阻力」，焓也不是普遍意义上的「驱动力」
  • 「衰老就是熵大于焓」也不能作为生物学解释
  • 可以把「驱动力—阻力」当作管理分析模型使用，不要把它当成热力学公式
捌

第六步 · 一定要加入时间

系统的关键要素会随时间变化
系统不是照片，而是一部电影。
老师讲得特别好的一点

今天某个因素可能不重要，三个月后可能成为主要瓶颈。例如一个业务刚开展：

第一阶段
缺患者
第二阶段
患者增加，缺人手
第三阶段
人手增加，医保费用压力出现
第四阶段
业务稳定以后，又开始关心质量、品牌、效率

所以，系统的关键要素会随时间变化。真正的系统思维必须不断问：现在这个系统处于哪个阶段？——这也正好把上一节辩证思维整合了进来。

玖

七问 · 重整系统分析模型

整理者建议丢开原课散乱顺序，直接记这一套

这一课真正值得长期掌握的，不是老师讲的「体用、缘起、偶性、焓、熵」等大量概念，而是他实际上已经搭出的一套很有价值的系统分析模型——再补上「反馈」，就会变得相当实用：

目的/功能
我们究竟希望实现什么？
边界
哪些因素属于这个问题？
要素
哪些人、资源、条件参与？
关系
它们怎样相互影响？
反馈
结果会不会反过来强化或抑制原因？
关键条件
最少必要条件与冗余在哪里？
驱动力/阻力
什么推动系统？什么限制系统？
时间
这些关系将怎样随时间变化？

整理者的原话：「我认为，这套七问比讲稿里大量『体用、偶性、缘起、焓熵』更值得长期掌握。」

拾

哲学概念的校正

康德、体用缘起、系统思维源流 · 整理者的批判性提醒，不要当标准定义记忆

原课把康德的「关系范畴」与因果、体用、缘起联系得非常紧，还谈了系统思维与控制论的历史——但有几处需要明显纠偏，以下都不要作为标准定义记忆。

校正一 · 康德「关系范畴」不能这样直接对译
  • 康德十二范畴中的「关系」确实有三组：实体—偶性、原因—结果、共同体/交互作用
  • 老师讲的「偶性」，更准确来说是哲学传统中的「实体与偶性」——例如一个苹果作为对象，「红色」「甜」等性质可以作为它的属性或偶性来讨论，而不是「偶然遇上一个东西，它的特性就发挥出来」
  • 把康德三种关系直接翻译成「因果＝因果思维、偶性＝体用、共同体＝缘起」，是老师自己的比较性解释，不能作为康德哲学的标准定义记忆

虽然不能与康德范畴一一对应，但这三种思想仍然可以成为三个观察角度。这三个问题组合起来其实非常好：原因 + 功能 + 条件网络，然后再进入系统。

因果

问：为什么发生？

追问原因与结果

体用

问：这个东西是什么，它能够发挥什么作用？

追问本体与功能

缘起

问：哪些条件共同出现，才使这个现象成立？

追问成立的条件网络

同一个对象，可以从不同关系类型进行观察。
整理者认为这才是老师真正有价值的地方
校正二 · 系统思维不是某一个人发明的
  • 原课语音里说「杰克的生物学家」，这里应该有识别错误——20世纪一般系统论的重要代表人物，是奥地利生物学家路德维希·冯·贝塔朗菲（Ludwig von Bertalanffy），1968年的《General System Theory》影响很大
  • 但说「系统思维就是一个生物学家发明的」仍然过度简化——现代系统思想还来自控制论、运筹学、系统动力学、系统工程、复杂性理论等多条传统
  • 「自动控制理论来自系统思维」也应调整：现代控制论的重要奠基人物是数学家诺伯特·维纳（Norbert Wiener），1948年《控制论》系统讨论机器和动物中的控制、通信与反馈
  • 更合理的说法：一般系统论 + 控制论 + 系统工程等共同推动了现代系统思维，而不是单向的「系统思维 → 自动控制」
拾壹

领导者思维与战略思维

局部最优 ≠ 整体最优 · 系统思维是战略思维的重要基础之一

为什么老师说「系统思维是领导者思维」？这句话虽然不是严格理论定义，但非常有管理意义：

基层执行者关注

  • 我这一件事怎么做好？

领导者必须进一步看到

  • 这件事情改变以后，会不会影响其他部门？
例增加住院患者，不能只看到「收入增加」▸
还必须看到：床位、护士负荷、药占比、耗材、医保额度、质量安全、患者满意度都会同时变化。很多管理错误都来自——一个科室指标变好了，但整个机构反而变差。系统思维就是要防止这种问题。
局部最优 ≠ 整体最优。
「领导者思维」的本质

战略思维为什么离不开系统思维？因为战略不是问「今天怎么解决一个问题？」而是在问「改变A以后，半年、一年、三年后整个系统会变成什么样？」——因此必须考虑要素、关系、时间、反馈、资源约束、外部环境。

整理者的校正
  • 更准确的说法是：系统思维是战略思维的重要基础之一
  • 而不是「没有系统思维就绝对不可能做领导」——现实中的领导能力还包括沟通、执行、判断、伦理、组织、专业能力等
拾貳

实战 · 画一张系统图

老师最后布置的作业，也是本课最实用的部分

整理者认为老师最后布置的作业非常好：选一个真实问题，不要写文章，而是画系统图。这个方法很适合实际工作，例如「为什么老年人体检完成率不高？」

三步画系统图的操作顺序▸
① 中央写「老年人体检完成率」，周围先放：居民认知、家庭医生、网格负责人、时间安排、体检流程、距离、联系方式、家属支持、绩效、宣传。
② 然后画箭头：哪些是因果？哪些相互强化？哪些互相制约？
③ 再标：哪些是可控因素？哪些是关键瓶颈？

到了这里，你对问题的理解会比「大家要加强宣传、提高积极性」高一个层级。

一个真正实用的系统图，至少应该包含：目的、边界、要素、关系、反馈、驱动力/阻力和时间。

拾叁

第五章收束 · 看因变联

四种思维记成四个问题，再压成四个字

第五章现在终于可以完整收束了。整理者建议把四种思维记成四个问题：

感性思维 · 看
发生了什么？

①系统模型环节归位

判断下列问题属于系统分析模型的哪个环节，点选后即时判分
1. 我们究竟希望实现什么？
2. 哪些因素属于这个问题？
3. 哪些人、资源、条件参与？
4. 哪些地方没有冗余，一旦失效整个系统就会中断？
5. 结果会不会反过来强化或抑制原因？
6. 改变A以后，半年、一年、三年后整个系统会变成什么样？

②系统分析通关清单

选一个你正面对的真实问题（如某项业务、某个指标），逐项检验自己能否做到
我能说清楚：我的目标到底是什么？哪些放进系统、哪些暂放系统外（目的与边界）
我能列全参与的人、资源、条件，且不只抓住最显眼的一个原因（要素）
我能画出它们之间的因果、并列、对立、调控关系，而不只是罗列清单（关系）
我能找到反馈环：哪些结果会反过来强化或抑制自己的原因（反馈）
我能找出最少必要条件与缺乏冗余的瓶颈，并分辨驱动力与阻力——知道有时减少阻力胜过更用力推（条件与驱动）
我能判断：现在这个系统处于哪个阶段？关键要素将怎样随时间变化（时间）

③终极测验 · 五题

Q1系统思维之所以强，强在哪里？
源文：「系统思维之所以强，不是因为它『淘汰』前三种思维，而是因为：它需要把前三种思维全部装进去。」系统里仍然需要观察现象、找到因果、理解矛盾和变化。
Q2「你怎样定义问题，就决定了……」这句话的后半句是什么？
源文：「你怎样定义问题，就决定了你会看见哪些因素。」「怎样提高医院收入」与「提高医疗服务能力＋控制医保风险＋保证质量和满意度」是两个边界完全不同的系统。
Q3在因果问题上，系统思维真正比普通因果分析强大在哪里？
源文：「因果不是一条直线，而可能是一个环。」一个结果产生以后，又回来影响自己的原因——这就是反馈，包括增强反馈与平衡/抑制反馈。
Q4对原课「焓是驱动力，熵是阻力」的说法，整理者的建议是什么？
整理者明确说「这部分建议你不要记」：恒温恒压下判断过程是否自发烧用吉布斯自由能 ΔG = ΔH − TΔS，熵并不是简单的「阻力」；但「驱动力—阻力」作为管理分析模型仍然实用。
Q5老师最后布置的作业是什么？
源文：「选一个真实问题，不要写文章，而是：画系统图。」中央写问题，周围放要素，画箭头标关系，再标可控因素与关键瓶颈——理解会比「加强宣传、提高积极性」高一个层级。
