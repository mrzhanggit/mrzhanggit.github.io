最核心的一句话 · 把感觉转换成问题

不是“所有问题都能解决” · 而是把感觉和情绪转换成问题

整理者认为不是这句 ✕

  • “所有问题都能解决。”

而是老师后面这句 ✓

  • 把感觉和情绪转换成问题。
  • 整堂课真正最值得长期记忆的思想

例如——

我最近工作很烦。
原始信号 · 这是感觉，还不是问题
再问：烦在哪里？
发现“网格化工作推进不顺。”——还是太宽
继续问：哪里推进不顺？
把模糊的“烦”一步步收窄
变成可以分析的问题
现状、数字、困难全部落地
10月份目标要求每人完成30名新增居民信息采集，但目前平均只完成12名，主要困难是居民白天不在家、联系方式缺失和工作人员下社区时间不足。
“烦”经过连续追问后的最终形态

到了这里，原来的“烦”已经变成可以分析的问题——这就是问题意识。

叁

三种问 · 疑问 设问 提问

认知缺口 → 分析框架 → 沟通行为 · 主动性层层递进

老师区分了疑问｜设问｜提问。这个框架很好，但整理者提醒：定义需要稍微调整。

①

疑问 · 我不知道

例：“为什么最近门诊量下降了？”
你已经感觉到有东西解释不了——它是一种认知缺口。
疑问 = 我发现自己不知道什么。

②

设问 · 我决定追究什么

设问比疑问更主动。例见下方金句——已经开始界定对象、设置方向、建立分析框架。
设问 = 把模糊疑惑变成值得系统研究的问题。

③

提问 · 我向别人获取信息

例：“今年没有续签家庭医生的居民，最主要原因是什么？”
这是沟通行为，向同事、专家、患者、AI提出。
提问 = 把问题表达出去，获取新的信息和视角。

疑问
发现不知道
设问
决定研究什么
提问
向外获取信息

康德的“先天综合判断如何可能？”确实可以看作这种高度结构化的哲学设问——这是《纯粹理性批判》的核心问题之一。

门诊量下降究竟来自患者需求下降，还是我们自身服务能力发生变化？
设问的典型例子 · 已经开始界定对象、设置方向、建立分析框架
肆

AI时代 · 会提问题为什么重要

重要的不是“会不会搜索” · 而是知不知道自己真正想解决什么

老师关于“AI时代会提问题越来越重要”的判断有现实意义。AI极大降低了查资料、初步归纳、写作、计算、比较的成本。因此人与AI协作时，越来越重要的能力不是简单的“我会不会搜索”，而是——我知不知道自己真正想解决什么。

泛泛之问 ✕

  • “帮我分析一下工作。”
  • 得到的东西可能很泛

结构化之问 ✓

  • 现状、目标、资源、约束一次给齐
  • AI获得的问题结构完全不同
目前居民档案建档率低，目标三个月提高10个百分点，现有7支家医团队，每周只能安排2小时入户。请分析主要瓶颈、可控变量和三种推进方案。
同一件事，结构化之后交给AI的问法
高质量AI使用不只是会提问，还包括提供足够背景、判断答案质量、核实事实、继续追问和迭代。
整理者对“AI时代提问论”的补充校正

所以——提问能力很重要，但不是全部。

伍

疑问与焦虑 · 一条需要调整的链

老师的传导链有道理 · 但不能绝对化

老师认为，网络带来的焦虑有一条传导链——

网络给我们大量信息
产生大量疑问
解决不了
焦虑
整理者校正：这条链有一定道理，但不能绝对化
  • 更准确的表达：信息过载 ＋ 不确定性 ＋ 缺乏行动路径，可能增加认知紧张和焦虑
  • 关键不在于“有疑问不好”。真正的问题是：疑问长期保持模糊，而且不知道下一步能做什么
  • 最好的解决路径往往不是消灭疑问，而是：疑问 → 问题化 → 可行动化

这和第一章《生活的焦虑》正好形成闭环。

陆

没有问题就没有思想 · 从矛盾到差距

问题决定思考的方向 · 不要与黑格尔的“矛盾”画等号

“没有问题就没有思想”——这句话非常重要。因为真正的深度思考通常都有对象：你必须知道到底是什么东西值得解释。牛顿不是坐在那里“我要思考宇宙”，而是具体追问——

天上的月球运动和地面物体下落之间，是否存在统一规律？
牛顿的具体追问——问题越清楚，思考才越可能深入
问题的质量，往往决定答案质量的上限。
整理者的引申 · 问题决定思考的方向

老师还把问题连接到“矛盾”，进入上一章的辩证思维。他的逻辑是：

世界在变化
变化中存在差异与张力
这种差异表现为矛盾
矛盾具体到生活，就是问题
整理者校正：不要把“问题”与黑格尔的“矛盾”完全画等号
  • 黑格尔的“矛盾”是一个相当特殊的哲学概念，而且其辩证过程中很多“对立”并不一定是严格形式逻辑意义上的矛盾
  • “现实问题 = 黑格尔矛盾”只能作为类比，不能把生活中的所有差距直接等同于哲学矛盾
问题 = 当前状态与期望状态之间存在值得处理的差距。
现实生活中更实用的理解 · 直接引出老师最重要的“五要素”
柒

问题五要素 · 本课核心成果

现状 → 目标 → 路径 → 资源 → 能力 · 差距是核心关系

这一课最核心的成果，就是老师提出的“问题五要素”。整理者认为这五个要素很值得保留，而且可以进一步升级成一套真正适合工作、学习和AI时代的问题分析模型。

问题的基本结构 · “差距”是连接现状与目标的核心关系

严格说，老师列出的“五个构件”是现状｜目标｜路径｜资源｜能力，而“差距”是连接现状与目标的核心关系——这就是本课最值得长期保留的模型。下面逐个展开。

捌

要素详解 · 现状与目标

现状必须事实化 · 现状＋理想构成问题的两个端点
首先弄清楚当下。
老师对第一要素“现状”的要求 · 非常正确

很多人解决问题的第一个错误：还没搞清现在是什么样，就急着想办法。比如“中心业务不好，要加大宣传”——先别急。应该先问：业务哪里不好？门诊？住院？公卫？哪个科室？什么时候开始？和去年相比？

感觉化的现状 ✕

  • “我感觉……”
  • “中心业务不好，要加大宣传”

事实化的现状 ✓

  • 现状必须事实化
  • 变成数据、事实、行为和具体情境
那你希望变成什么样？
老师对第二要素“目标”的追问——否则根本没有“问题”

有了现状，必须问目标。比如当前收入400万元/月：如果目标也是400万元，那就没有差距；如果目标450万元/月，问题出现——差距 = 50万元。老师说，现状＋理想构成问题的两个端点，这是非常有价值的。

“理想”容易太抽象 ✕

  • “我要成为成功的人。”——很难解决

改成“目标状态” ✓

  • “三年内完成某项专业能力建设。”——更容易分析、拆解、行动
  • 现状 Current State ＋ 目标 Target State → Gap 差距
玖

要素详解 · 路径 资源 能力

路径通常不是唯一的 · 目标必须接受资源约束 · 资源 ≠ 能力

知道我在哪里、我要去哪，还不够，必须问：怎么过去？例如目标是“提升居民健康档案完整率”，路径可能有——

入户电话补录门诊同步采集社区集中活动与物业合作

这时候老师强调：路径通常不是唯一的。低质量思维往往是“只有这个办法”；高质量思维会问“还有没有第二条、第三条路径？”

路径不是想出来就能走，还必须问我有什么？——人员、资金、时间、设备、政策、信息、关系网络。老师用高考专业选择举例：不同学生可使用的分数、家庭条件、地区、学校资源不同。

整理者校正：原课关于专业选择的说法过于绝对
  • 原课有一句：“成绩不高，学生物学就学不出来；一定要很高排名大学才有机会。”——这个说法过于绝对
  • 专业发展受到学校平台、个人能力、研究机会、兴趣、学历路径、行业变化等多因素影响，不能只按学校层级下结论
  • 这里真正应该留下的是：目标必须接受资源约束
资

资源

“我可以调用什么？”
人员、资金、时间、设备、政策、信息、关系网络

能

能力

“我能够把这些资源转化成什么结果？”
资源 ≠ 能力，非常值得区分

有数据，但不会分析；有资金，但没有项目管理能力；有AI，但不会定义问题。同样100万元预算，不同团队可能得到完全不同结果——这就是能力差异。

整理者的升级 · 问题六问与实例

在五要素外增加“约束” · 从模糊感觉到可决策模型

在真实工作里，整理者建议在五要素之外再增加一个“约束”，把模型升级成“问题六问”：

① 现在怎样？
现状
② 想到哪里？
目标
③ 差多少？
问题差距
④ 可以怎么走？
路径
⑤ 有什么可调用？
资源与能力
⑥ 什么不能忽视？
约束、风险、规则

于是，问题从模糊感觉变成真正可以决策的模型。举一个实际管理例子——

老年人体检工作推进不好。
问题化之前的原始感觉
实例老年人体检 · 经过问题化之后▸
现状：本月每人要求3人，目前平均完成1.2人
目标：月底前每人完成3人
差距：平均每人差1.8人
路径：入户、电话邀约、集中体检、家属协助、门诊同步
资源：网格人员、居民档案、家庭医生联系方式、社区场地
能力：谁擅长联系居民？谁熟悉楼栋？谁可以完成体检？
约束：时间、居民配合、人员排班
延伸职业选择也是一个问题结构▸
原课“喜欢人就学经济政治，喜欢物就做研究”——这分类太粗。真正值得留下的是：选择专业不要只问“哪个专业热门？”，而应该同时看：我现在是谁？我想成为什么？有哪些现实路径？我有什么资源？我有什么能力和兴趣？

到了这里，问题就不再是“大家不积极”，而开始变成可以管理的结构。

问题的四种类型与五条路径

“所有问题都能解决”过强 · “时间解决一切”不成立 · 三路径升级为五
一旦转换成问题，就一定可解决。
老师的原话 · 整理者认为这一句最好改掉
整理者校正：并非所有问题都有完全解
  • 这种表达很有激励性，但现实并非所有问题都有完全解。有些问题只能：改善、管理、权衡、接受、延缓、降低损失
  • 例如：衰老、不可逆损失、价值冲突、资源不足

进行权衡

调整关系与接受

所以成熟的问题意识应该是：先判断这个问题属于哪一种。这其实与第一章《生活的焦虑》高度一致。

时间会改变问题，但不保证自动解决问题。
整理者对“时间可以解决一切问题”的校正

时间有时候确实会改变条件、关系、优先级，但时间也可能让问题恶化——感染不治疗，时间不会自动治好所有患者；债务持续累积，拖延可能越来越严重。真正需要问：随着时间推移，这个问题是在自我缓解，还是自我强化？这就是系统思维。

① 自我行动
改变自己可控的变量
② 借助系统
调用他人的知识、资源、组织和AI
③ 改变时间策略
等待时机、分阶段解决
④ 调整目标
如果目标不现实，重新设定
⑤ 接受不可控部分
不是所有变量都必须改变
拾貳

创造力的入口 · 烦恼即菩提

问题 → 张力 → 探索 → 创造 → 新方案 · “烦恼即菩提”只作比喻

“问题调动创造力”是这一课第二个非常好的观点。为什么创新通常从问题开始？因为没有问题时，“原来的方法还能工作”，人没有强烈理由改变。当出现现状 ≠ 目标，就形成张力——传统路径不够用，于是开始寻找新办法、新资源、新组合。

问题
现状 ≠ 目标，出现差距
张力
传统路径不够用
探索
寻找新办法、新资源、新组合
创造
新组合诞生
新方案
问题也可能是创造力的入口

所以问题并不只是负担——问题也可能是创造力的入口。

烦恼就是问题，菩提就是解决问题的能力。
老师对“烦恼即菩提”的解释 · 很现代、很工具化
整理者校正：“烦恼即菩提”适合作为比喻，不宜机械解释
  • 这不是佛教原意的严格定义。“烦恼即菩提”在大乘佛教语境中并不是简单说“遇到困难 → 想办法 → 智慧”，更深地涉及烦恼与觉悟并非两个具有独立自性的实体，以及如何转化对烦恼的认识
  • 作为生活语言，可以理解成“困扰也可能成为觉察和成长的入口”；但不要直接背成“烦恼=问题，菩提=问题解决能力”
困扰也可能成为觉察和成长的入口。

拾叁

问题转化器 · 从“烦死了”到行动

七步框架 · 这一课与前面所有课程连成总链
烦死了。
转化器的入口——脑子里出现的原始信号

以后当你脑子里出现这句话，不要直接想答案，按照下面走——这实际上已经是一套非常成熟的问题解决框架：

第一步 · 感觉
我哪里不舒服？
第二步 · 事实
具体发生了什么？
第三步 · 现状
现在到底是什么状态？
第四步 · 目标
我希望变成什么状态？
第五步 · 差距
阻止我达到目标的是什么？
第六步 · 路径
有哪些办法？
第七步 · 资源 / 能力
我现在能调用什么、缺什么？
最后才进入：行动
感觉 → 事实 → 结构 → 行动

这一课最需要纠偏的6点（整理者）
  • 哲学不必定义为“源于设问”，更稳妥地说哲学高度依赖惊异、质疑和系统追问
  • “疑问—设问—提问”是一个很好用的课程框架，但不是哲学或心理学统一认可的标准三分法
  • 康德确实以“先天综合判断如何可能？”作为《纯粹理性批判》的核心问题之一，这可以很好说明高度结构化的哲学设问
  • “现实问题=黑格尔矛盾”只能作为类比——黑格尔的矛盾与辩证运动有特殊哲学含义，不能简单把生活中的所有差距直接等同于哲学矛盾
  • “所有问题都能解决”过强——更成熟的是区分可解决、可改善、需权衡和需接受的问题
  • “时间解决一切”不成立——时间只是一个变量，它既可能缓解问题，也可能使问题恶化

如果这一课只记住6句话——

深度思考不是从答案开始，而是从发现并定义一个真正值得解决的问题开始。
六句话 · ①
疑问是“我不知道”，设问是“我要研究什么”，提问是“我向别人或AI获取什么信息”。
六句话 · ②
一个完整的问题至少应该包含：现状、目标、路径、资源和能力；现实决策中还应加入约束与风险。
六句话 · ④
把模糊的感觉和情绪转化成清晰的问题，本身就会显著提高行动感，因为你终于知道下一步可以分析什么。
六句话 · ⑤

③（问题最基本的结构，是现状与目标之间存在一个值得处理的差距）与⑥（真正的问题意识）已收入下方“带走三句”。

Q1这一课最核心的成果是什么？
老师提出的“问题五要素”——现状 → 目标 → 路径 → 资源 → 能力，是本课最核心的成果；整理者认为可以升级成适合工作、学习和AI时代的问题分析模型。
Q2整理后，疑问、设问、提问分别对应什么？
疑问：发现不知道 → 设问：决定研究什么 → 提问：向外获取信息。整理者同时提醒：这是好用的课程框架，但不是哲学或心理学统一认可的标准三分法。
Q3当前收入400万元/月，目标450万元/月——按照本课的框架，“问题”是什么？
问题 = 现状与目标之间的差距。目标也是400万元就没有差距；目标450万元，问题出现——差距 = 50万元。现状＋理想构成问题的两个端点。
Q4对老师“一旦转换成问题，就一定可解决”这句话，整理者的校正是？
有些问题只能改善、管理、权衡、接受、延缓、降低损失——例如衰老、不可逆损失、价值冲突、资源不足。成熟的问题意识是先判断问题属于哪一种。
Q5与AI协作时，越来越重要的能力是什么？
“帮我分析一下工作”得到的东西可能很泛；结构化的问题让AI获得的问题结构完全不同。整理者补充：高质量AI使用还包括提供足够背景、判断答案质量、核实事实、继续追问和迭代。

④带走这三句

本讲最值得长期记住的三句话 · 复习时先默背再看原文
问题不是“我感觉不对”，而是我知道自己现在在哪里、想去哪里，以及两者之间究竟差什么。
整理者最推荐的这一课信息图中心金句
现状 → 目标 → 路径 → 资源 → 能力
本课最值得形成长期视觉记忆的模型
真正的问题意识不是“到处找麻烦”，而是能够看见差距、界定问题，并找到其中可以改变的变量。
