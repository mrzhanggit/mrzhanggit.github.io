本篇是第一次范式更替的收束：旧拼图雪崩，新拼图成型

接受了运动的地球，亚里士多德世界观核心拼板崩塌，问题如滚雪球——从「我们为什么不飞出去」到「宇宙还有中心吗」。第19章展示哲学/宗教/科学如何相互成全（冯·库斯与布鲁诺的「概念创可贴」、原子论与惯性定律）；第20章牛顿《原理》为新拼图提供核心科学拼板：一个机械论的宇宙。

貳

第18章 · 运动的地球带来了什么问题

PROBLEMS

假设我们生活在17世纪上半叶，已经接受开普勒的体系：地球和其他行星沿椭圆轨道变速绕太阳运转，地球每天自转一圈。这一接受，亚里士多德世界观的拼图立刻成片脱落：

旧拼板为什么保不住了
重物向宇宙中心运动的天然趋势地球不是宇宙中心 → 无法再解释什么使我们留在地球表面、重物为何下落
运动物体总会停下来（17世纪前运动定律）地球一直在运动，没有外界因素使其保持运动 → 这块拼板一定是错的
上抛物体落回原处（基于运动物体论据）若地球在动，上抛物体应落到身后——新科学必须重写运动理论
常识论据自转速度1000英里/小时、公转近70000英里/小时，为什么没有强风、震动？
天空是完美的地方椭圆轨道与变速运动不适合完美的天空——严峻挑战
宇宙较小、较舒适没观察到恒星视差 → 恒星遥远到难以置信 → 宇宙大到无法想象，甚至无限大
恒星球面与宇宙中心恒星散布在浩瀚宇宙之海中 → 没有恒星球面就没有边界，没有边界谈何中心 → 元素的天然运动全部站不住脚
目的论与本质论基本元素的运动不能再从神学、本质论角度描述 → 「宇宙有目的、有本质存在」的整体观点受质疑

某些宗教观点同样受到冲击：为什么要创造一个空间大多被浪费的宇宙？地球只是一粒尘埃，人类扮演什么角色？基督教的上帝曾在天体运动的科学解释中占有一席之地（天体渴望模仿上帝的完美），如今这个解释也行不通了。

这是第1章拼图比喻的实证：核心拼板一动，相连观点如滚雪球般次第脱落——对旧拼图修修补补已不现实，需要的是一个全新的世界观，以及作为其一部分的新科学。

叁

新科学的需求与「几点注意」

NEEDS

需求有多迫切？2000多年来整个亚里士多德科学体系几乎完全建立在地心宇宙之上，地心说瓦解同时意味着这个科学体系瓦解——而且没有替代品。17世纪早期，连「石头为什么会向下落」这样简单的问题都不存在解释；我们为什么感觉不到地球的高速运动、上抛物体为什么落回原处、行星最初的运动从何而来，全都没有答案。

新科学必须能与运动的地球保持一致。

德威特随即提醒两点，以免产生误导：其一，旧拼图并非2000年不变——宗教观点在中世纪被加入、运动观也得到修改（为惯性定律创造了条件），但它仍是亚里士多德世界观。

其二，不要认为牛顿是有意去填补亚里士多德体系瓦解后的真空——牛顿跟我们一样是复杂的个体，受一系列复杂因素影响：与竞争者的较量、早期成果的接受情况、性格冲突、优先权之争，甚至可能还有童年与母亲的关系。人物与事件背后的微妙因素，比简单化的叙事多得多。

肆

第19章 · 宇宙有多大：比例尺下的震撼

SCALE

17世纪是美妙的时代——科学、哲学、宗教、政治的变革相互影响，出人意料。第19章挑了一条线：宇宙的大小。设一个比例尺：地球 = 直径1英尺的常见地球仪。那么——

比例尺一

太阳与冥王星

太阳相当于一幢10层高的大楼，距离地球约2英里；长期被认为最远的行星冥王星（今认定为矮行星）只有网球大小，位于80英里之外。

比例尺二

塞德娜与整个太阳系

矮行星塞德娜的轨道极其古怪，大约再过几十年它会运行到2000英里以外——想给行星系统做准确的比例模型，需要的面积将是美国大陆的一大半。

比例尺三

最近的恒星

太阳只是银河系上千亿颗恒星中的一颗；除太阳外离我们最近的恒星在500000英里之外——恒星彼此相隔几乎超乎想象的空间。

比例尺四

星系与星系之外

银河系由上千亿颗恒星组成（肉眼最多看到约3000颗）；而银河系只是可见宇宙中数以千亿计的星系之一。宇宙之大，难以想象。

想象17世纪早期的欧洲人：从小接受的是「上帝为人类创造了一个较小、较舒适、地球居中的宇宙」，几乎一夜之间，地球成了大海中的一滴水。所幸此前几个世纪，尼古劳斯·冯·库斯（1401—1464）与乔达诺·布鲁诺（1548—1600）已从哲学与宗教角度主张宇宙无限大——唯有这样的宇宙才与无限伟大的上帝相称。

布鲁诺也因这些主张，于1600年被当作异教徒活活烧死。

他们认为，无限大的宇宙反映了上帝的无限伟大，这个观点有助于使这些难以理解的新观点得到接受。——第19章 宇宙的大小

德威特称之为某种概念上的创可贴：巨大的宇宙在概念上本来没有意义，需要一种方法把它与我们对宇宙的整体认识拼合在一起。

与之相连的是复兴的原子论（留基伯、德谟克利特、伊壁鸠鲁、卢克莱修一脉，17世纪称「微粒」观点）：世界由原子和虚空组成，原子像台球一样沿直线运动、碰撞后弹开——它更多是形而上学的哲学观点，却与发展新科学成果显著。

伍

从原子论到惯性定律

ATOMISM

惯性定律是17世纪最难理解的定律之一——它与日常经验完全矛盾。但把两件事放在一起看，它突然变得可以理解了：接受宇宙无限大，并按原子论来认识宇宙——一个在空间中运动、绝不与其他原子碰撞的原子会如何运动？答案是：永远保持直线运动。实际上这就是惯性定律。

笛卡尔正是受原子论（微粒）观点的影响，第一个清晰表述了惯性定律——这并不是巧合。

德威特随即补上分寸：不能认为惯性定律只是接受宇宙无限大和运用原子论的结果——它通过实验、新方法与许多人长期的努力才被发现。重点是：通常被认为相互独立的领域，彼此之间的相互影响多到令人惊讶——形而上学、哲学性/概念性与宗教观点，和最直接明确的科学发现，是携手前进的。

陸

第20章 · 《原理》：新科学的核心

PRINCIPIA

17世纪新科学是许多人几十年的共同努力（同时期莱布尼茨独立创立了微积分），而把这些努力汇集在一起的，是牛顿1687年的《自然哲学的数学原理》（简称《原理》，最新英文译本约600页）。其核心是三大运动定律与万有引力定律：

定律内容
牛顿第一运动定律惯性定律：任何物体在不受任何外力的作用下，总保持匀速直线运动状态或静止状态，直到有外力迫使它改变这种状态（很大程度上借鉴笛卡尔的表述）
牛顿第二运动定律物体运动的改变与其所受作用力成正比，且在一条直线上——F=ma；击棒球越用力，球飞得越快越远
牛顿第三运动定律对任何作用力，总存在方向相反、大小相等的反作用力——标准解释是手枪的后坐力
万有引力定律任意两个物体之间的相互吸引力；与质量成正比、与距离的平方成反比

有趣的是写法上的差别：三大运动定律在开篇10页就完整简明地给出（在《原理》中只占两页纸），万有引力却是逐渐展开的——开篇定义部分「重力」还只指把物体往地球方向吸引的作用力；400页以后才表明地球重力影响了月球轨道、其他卫星与行星轨道上的作用力性质相同；直到第三卷命题七，才提炼出完整概念——

重力普遍存在于一切物体中。——第20章 新科学
柒

牛顿世界观：一台机器，一位钟表匠

MACHINE

亚里士多德世界观

  • 宇宙较小、较舒适，地球居中心
  • 物体因内在本质属性而运转，宇宙充满目标和目的
  • 天体持续运动需要神明（后被宗教中的上帝接替）
  • 每个人在整体环境中都有天然位置（等级观，如君权神授）

牛顿世界观

  • 宇宙广阔、甚至可能无限大，太阳只是太阳系中心
  • 物体在外力（推拉）作用下运转，没有目的——宇宙像一台机器
  • 行星运动=惯性+重力，不再需要上帝使宇宙运转
  • 上帝变成设计并「上好发条」的工程师/钟表匠，此后宇宙自行运转
事实上，宇宙一天一天保持运转，就像钟表每天嘀嗒嘀嗒走个不停。——第20章 牛顿世界观概述

社会观念也随之变化：坚持「君权神授」信条的最后一代君主中有英国国王查理一世——17世纪40年代他被推翻、审判并处决时仍在维护这个信条。而发生在17世纪40年代的英国革命，以及随后的美国、法国革命都以个人权利为重点诉求，这些都发生在亚里士多德世界观被摒弃以后——很可能这并不是巧合。

捌

哲学思考：重力是科学还是魔法

GRAVITY

用现实主义态度看牛顿的重力，它其实相当奇怪。做个测试：让钢笔移动，但不许碰它、吹气、扔东西、摇桌子——与钢笔有任何形式的联系都不行。你肯定会认为这是不可能的任务，其背后的判断至少可追溯到古希腊：「超距作用」不可能存在——一个物体不可能在没有任何联系的情况下影响另一个物体。

可重力正是这样：两支钢笔被拉长的橡皮筋连着，吸引力很容易理解；但下落的钢笔与地球之间没有橡皮筋、没有细绳，什么都没有，钢笔却照样向地球移动。从这个角度看，重力听起来并不像科学，而像魔法。

难怪开普勒提出潮汐可能受月球影响（方向正确）时遭到大肆批评——包括来自伽利略的批评；《原理》发表后，莱布尼茨等人攻击牛顿在科学中引入了「超自然」的力。

牛顿的回应是采取工具主义态度：方程式（包括重力相关方程式）可以很好地预测钢笔如何下落，同时对重力是不是「真实」的力保持不可知论。牛顿本人其实一直希望给出不涉及超距作用的现实主义描述，但此后两个世纪都没有出现完全令人满意的解释——

至少从现实主义角度来看，这些解释都有问题。只要采取完全的工具主义态度，那么所有解释，包括牛顿的解释，都是没有问题的。——第20章 哲学思考

最终，爱因斯坦的广义相对论将对重力给出一个不涉及超距作用的解释——但与我们从小理解的牛顿重力观存在巨大差异。那是第三部分的故事。
